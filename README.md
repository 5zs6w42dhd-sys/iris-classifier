Iris Classifier
Presentation
Iris Classifier est un petit projet realise avec Python pour decouvrir les bases du Machine Learning.
Le but est de creer un modele capable de predire l'espece d'une fleur Iris a partir de quatre mesures : la longueur et la largeur de ses sepales et de ses petales.
Ce projet est une premiere etape dans mon apprentissage de Python et de l'intelligence artificielle.
Objectifs
Decouvrir le fonctionnement d'un modele de Machine Learning.
Apprendre a utiliser un jeu de donnees avec Python.
Creer des graphiques pour mieux comprendre les donnees.
Entrainer un modele et tester ses predictions.
Comprendre comment evaluer les resultats d'un modele.
Technologies utilisees
Python : langage de programmation.
scikit-learn : chargement des donnees Iris et creation du modele.
pandas : organisation des donnees sous forme de tableau.
matplotlib : creation de graphiques.
Google Colab : environnement utilise pour ecrire et executer le code.
Le jeu de donnees
Le projet utilise le jeu de donnees Iris fourni par scikit-learn.
Il contient 150 observations reparties en trois especes :
Setosa
Versicolor
Virginica
Chaque fleur est decrite par quatre caracteristiques numeriques, mesurees en centimetres.
Fonctionnement du projet
Le projet suit plusieurs etapes :
Charger le jeu de donnees.
Afficher les premieres observations.
Explorer les caracteristiques et visualiser les donnees.
Separer les donnees en un ensemble d'entrainement et un ensemble de test.
Entrainer un modele K-Nearest Neighbors (KNN).
Evaluer les predictions du modele.
Tester le modele sur de nouvelles mesures de fleur.
Resultats
Lors de mon test, le modele a obtenu une accuracy de 100 % sur les 30 observations de test.
Il a egalement predit l'espece setosa pour un exemple de fleur dont les mesures etaient :
Longueur du sepale : 5.1 cm
Largeur du sepale : 3.5 cm
Longueur du petale : 1.4 cm
Largeur du petale : 0.2 cm
Ce resultat concerne uniquement cette execution et cet ensemble de test. Il ne garantit pas que le modele sera toujours correct sur de nouvelles donnees.
Ce que j'ai appris
Grace a ce projet, j'ai decouvert comment :
Charger et explorer un jeu de donnees.
Utiliser des graphiques pour comparer des observations.
Separer des donnees pour entrainer et tester un modele.
Utiliser l'algorithme KNN pour effectuer une classification.
Mesurer les performances d'un modele avec l'accuracy.
Realiser une premiere prediction avec Python.
Ameliorations possibles
Pour continuer a apprendre, je pourrais :
Tester differentes valeurs de K.
Comparer les performances de plusieurs modeles.
Explorer d'autres jeux de donnees.
Conclusion
Ce projet m'a permis de decouvrir les premieres etapes d'un projet de Machine Learning. Il constitue une base pour continuer a apprendre Python, la science des donnees et l'intelligence artificielle.
